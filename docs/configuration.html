Configuration

💬

Error message #42: "Your .env has opinions. Your .env is wrong."

Two files control the tool: key-bitcher.toml (runtime behavior) and
.env (your secrets). Both are read from the working directory by default.

key-bitcher.toml

[s3]              # which bucket is the source of truth
bucket = "wave-secrets-bucket"
region = "eu-central-003"
object_key = "secrets/ai-keys.json"

[secrets]         # how .env is written
output_env_file = ".env"
overwrite_existing = true

[wave]            # Wave secret store (optional)
# wsh_path = "C:\\Users\\you\\AppData\\Local\\waveterm\\Data\\bin\\wsh.exe"

[logging]         # rotating file logger (optional)
# max_size_bytes = 5242880

[benchmark]       # providers pinged by `benchmark`
models = [
  "openai:gpt-4o-mini",
  "openrouter:google/learnlm-1.5-pro-experimental",
  "anthropic:claude-3.5-sonnet",
  "mistral:mistral-large-latest",
]
max_output_tokens = 256
request_timeout_secs = 30

[sections]        # override working.md section -> env-var mapping (optional)
# "My Custom Section" = ["MY_CUSTOM_KEY_1", "MY_CUSTOM_KEY_2"]

Section mapping

import-md maps ## Section headings in working.md to env-var names via a
built-in table. Entries in [sections] override the built-in mapping for
that heading. This is how you wire a handout whose headings don't match the
default naming.

Why these defaults

  • overwrite_existing = true — a sync-secrets is meant to converge .env
    to the bucket. Set false to refuse overwriting a local .env you edited.
  • max_output_tokens / request_timeout_secs — keep benchmark cheap and
    bounded; a hung model must not hang your daily flow.

.env

Plaintext KEY=VALUE pairs. See .env.example for the full template. The
real .env is gitignored; on shared machines lock it down with
key-bitcher secure.

Alternates exist because providers fail over: benchmark tries all keys per
provider, promotes the first working one, and notifies you. See
Architecture.

How paths are resolved

  • Config: --config <PATH> else ./key-bitcher.toml.
  • wsh: [wave] wsh_path else PATH lookup, else the default Windows
    install location (%LOCALAPPDATA%\waveterm\Data\bin\wsh.exe).
  • Log file: --log-file <PATH> else key-bitcher.log in the working dir.

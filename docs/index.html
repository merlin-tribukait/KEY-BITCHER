02. Quick Installation

You need a Rust toolchain (1.70+). Install via the build script (recommended):

.\build.ps1 -Profile release -Test

Or straight from source:

cargo build --release

Full walkthrough in Getting Started.

💬

You don't have a bug. You have a feature that committed its own API key.

03. Configuration

Place this key-bitcher.toml in your project root. DO NOT EDIT RANDOM KEYS.

[s3]
bucket = "wave-secrets-bucket"
region = "eu-central-003"
object_key = "secrets/ai-keys.json"

[logging]
